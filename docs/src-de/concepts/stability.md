# Stabilitätsstatus

| Symbol | Bedeutung des Contracts |
|:---:|---|
| ✅ | Im auf der Seite genannten Production-Provider implementiert und verfügbar |
| 🧪 | Öffentlicher Contract oder kontrollierter Test-Provider; kein Production-Game-Provider |
| 🚧 | Geplant oder in aktiver Entwicklung; nicht davon abhängig werden |
| ❌ | Explizit nicht verfügbar |

Der Status gehört zu einer konkreten Version und einem Provider. Ein stabiler Header bedeutet nicht, dass in jedem Prozess ein Provider existiert. Runtime-Discovery und Capability-Abfragen verwenden.
