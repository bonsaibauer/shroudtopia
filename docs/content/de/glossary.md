# Glossar

| Begriff | Bedeutung |
|---|---|
| ABI | Binärvertrag zwischen Mod und Loader. |
| Capability | Versioniertes Runtime-Feature, das verfügbar oder nicht verfügbar sein kann. |
| Ownership | Verantwortung für Aufbewahrung und Freigabe von Speicher oder Handles. |
| Registration | Handle einer registrierten, einer Mod zugeordneten Ressource. |
| Service | Versionierte Erweiterungsschnittstelle, die zur Laufzeit ermittelt wird. |
| StringView | Nicht besitzender UTF-8-Bytebereich ohne garantierte Nullterminierung. |
