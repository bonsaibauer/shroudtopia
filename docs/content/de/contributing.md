# Dokumentation beitragen

Für jede öffentliche API-Änderung:

1. Header, Implementierung und Verhaltenstests aktualisieren;
2. den passenden Contract in `docs/contracts` mit Feldern, Parametern, Ownership, Lifetime, Threading, Ergebnissen, Version und Beispiel aktualisieren;
3. englische und deutsche Konzepte/Guides bei Semantikänderungen aktualisieren;
4. `npm run docs:check` ausführen;
5. sichtbare Änderungen auf Desktop/Mobil sowie in hellem/dunklem Theme prüfen.

Generierte Seiten tragen eine Warnung und dürfen nicht manuell bearbeitet werden. Die Pfade in englischer und deutscher `SUMMARY.md` müssen identisch bleiben.
