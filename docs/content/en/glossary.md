# Glossary

| Term | Meaning |
|---|---|
| ABI | Binary contract between a mod and the loader. |
| Capability | Versioned runtime feature that may or may not be available. |
| Ownership | Responsibility for retaining and releasing memory or handles. |
| Registration | Handle for a registered resource owned by a mod. |
| Service | Versioned extension interface discovered at runtime. |
| StringView | Non-owning UTF-8 byte range; not necessarily null-terminated. |
