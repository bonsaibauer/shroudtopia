# Stability status

| Symbol | Contract meaning |
|:---:|---|
| ✅ | Implemented and available in the production provider described on the page |
| 🧪 | Public contract or controlled test provider; not a production game provider |
| 🚧 | Planned or actively developed; do not depend on it |
| ❌ | Explicitly unavailable |

Status belongs to a precise version and provider. A stable header does not imply that a provider exists in every process. Use runtime discovery and capability queries.
