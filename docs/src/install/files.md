# Requirements and Files

| Requirement | Value |
|---|---|
| Operating system | Windows x64 |
| Runtime | Microsoft Visual C++ Runtime |
| Game process | Enshrouded client or dedicated server |

A release archive contains `winmm.dll`, `shroudtopia.dll`, and
`shroudtopia-assets.dll`. Use all DLLs from the same release artifact. The product
version is stored in `VERSION`.
