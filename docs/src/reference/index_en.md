# API reference

This reference is generated from validated contracts and mirrors the public C headers. Each service page starts with provider, version, status, capability, and header, followed by field-complete types and function contracts.

## Reading a function

- **Direction** distinguishes input, output, and initialized input/output memory.
- **Required** says whether the argument may be absent under documented conditions.
- **Ownership** and **threading** apply in addition to parameter-specific rules.
- **Results** list meaningful result causes; always handle unknown future failures safely.
- **Since** is the service minor version, not the repository release.

The headers remain the normative binary layout. If generated reference and behavior disagree, file a bug and trust neither silently.
