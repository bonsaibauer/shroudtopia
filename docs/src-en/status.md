# Status and roadmap

The contract pages are the canonical status source. Today the Host, Asset, Logging, Runtime Patch, and Text UI providers are implemented. World 1.1 is a public contract with a controlled ShroudEdit test provider, not a production Enshrouded provider.

Planned areas include game targeting, production entity/grid integration, game-thread jobs, renderer overlays, live asset reload, archived-log enumeration, richer settings readers, and generated settings UI. Planned features must not be inferred from headers or roadmap prose; discover them at runtime.
